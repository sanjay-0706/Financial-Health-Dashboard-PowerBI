📊 Financial Health Dashboard

Overview
This project analyzes revenue, expenses, profit, and overall financial performance using Power BI. The dashboard provides insights into financial trends and key business metrics.

Objectives

Monitor Revenue and Expenses
Track Net Profit and Profit Margin
Analyze Sales Performance
Generate Business Insights

Financial Analysis

Financial Insights

Tools Used
Power BI
DAX
Power Query

Key Insights
Revenue reached 118.7M.
Net Profit reached 16.9M.
Profit Margin remained above 14%.
Government segment contributed the highest sales.
